# 🎓 EduStatus Chile — Estado de Plataformas Educativas

**EduStatus Chile** es una aplicación web interactiva inspirada en Downdetector, diseñada para monitorear en tiempo real la disponibilidad, incidentes y caídas de las principales plataformas educativas en Chile (Lirmi, Syscol, Mateo, Webclass, SIGE, Napsis, entre otras).

Desarrollado y mantenido por **ECOO EMPRESAS**.

---

## 🚀 Características

- 📊 **Monitoreo en tiempo real:** Visualización gráfica de las fallas reportadas durante las últimas 24 horas.
- 🚦 **Indicadores de estado:** Clasificación visual (*Operativo*, *Problemas menores*, *Interrupción grave*).
- 🚨 **Módulo de reporte rápido:** Permite a docentes, administrativos y apoderados informar fallas clasificadas por tipo (Inicio de sesión, Carga de notas, Plataforma offline, etc.).
- 💬 **Muro de comentarios y comunidad:** Espacio interactivo para compartir feedback e incidencias en tiempo real.
- 🔍 **Filtros por tipo de plataforma:** Búsqueda rápida por Gestión Escolar (LMS/SIGE), Plataformas de Aprendizaje y Herramientas del Mineduc.
- 📱 **Diseño Responsive:** Optimizado para dispositivos móviles, tablets y escritorio con Tailwind CSS.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica.
- **Tailwind CSS (via CDN):** Diseño moderno, accesible y responsivo.
- **JavaScript (Vanilla ES6+):** Lógica interactiva, gestión de estado local, simulación de datos en tiempo real y componentes dinámicos.
- **FontAwesome:** Iconografía técnica e interactiva.
